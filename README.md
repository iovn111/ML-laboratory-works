# Лабораторные работы по машинному обучению

Учебные работы по курсу машинного обучения (НИУ ВШЭ, «Бизнес-информатика»). Каждая работа хранится в отдельной папке вместе с исходными данными, ноутбуком и результатами.

> ⭐ **Главный проект — [прогнозирование спроса на велопрокат (ДЗ3)](ДЗ3)**: проверка качества данных, регрессия и классификация дней высокого спроса. Подробное описание, результаты и графики — в README папки.

| [ДЗ2](ДЗ2) | Прогнозирование временного ряда мощности здания на сутки вперёд | Энергопотребление здания | [solution2.ipynb](ДЗ2/solution2.ipynb) |

## Запуск

Установите зависимости:

```bash
pip install -r requirements.txt
```

Откройте Jupyter Notebook из папки нужной работы, чтобы относительные пути к CSV-файлам работали корректно:

```bash
cd ДЗ1
jupyter notebook
```
